# Taller UX

Formulario de inscripción rediseñado aplicando principios de UX/UI.

**Página publicada:** [https://github.com/joelrimachi/taller-ux.git]
## Cambios aplicados

| Principio | Cambio |
| :--- | :--- |
| **Visibilidad del estado** | Mensaje de envío, de error y de éxito |
| **Prevención de errores** | Campos obligatorios y validación del correo |
| **Control y libertad** | Confirmación antes de limpiar el formulario |
| **Ley de Fitts** | Botón principal grande y separado de Limpiar |
| **Ley de Hick** | Talleres agrupados por categoría |
| **Accesibilidad** | Labels, texto alternativo, contraste y foco visible |
